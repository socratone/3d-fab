# React + TypeScript로 반도체 공장 만들기

## 목표와 기술 구성

**React Three Fiber로 작은 공장을 단계적으로 만들면서, 바탕이 되는 Three.js 개념을 함께 익힌다.** 프로젝트는 빈 폴더에서 시작하며, 첫 구현은 화면에 박스 하나를 표시하는 것으로 제한한다.

- **Vite + React + TypeScript:** 개발 환경과 화면 구성.
- **pnpm:** 패키지 설치와 스크립트 실행. `pnpm-lock.yaml`을 사용한다.
- **Three.js + React Three Fiber:** 3D 장면 구성.
- **Drei:** 카메라 조작용 `OrbitControls`가 필요한 단계부터 추가.
- **일반 CSS:** 화면 크기와 간단한 정보 패널 스타일.
- React 19와 Fiber 9를 기준으로 호환되는 안정 버전을 사용한다. [공식 호환 안내](https://r3f.docs.pmnd.rs/getting-started/installation)

## 단계별 구현

| 단계 | 구현 결과 | 학습 개념 |
|---|---|---|
| 1 | 화면에 박스 하나 표시 | `Canvas`, `mesh`, geometry, material |
| 2 | 바닥과 격자 위에 박스 배치 | 좌표축, `position`, `rotation`, `scale` |
| 3 | 마우스로 회전·확대·이동 | 원근 카메라, `OrbitControls` |
| 4 | 조명으로 장비 입체감 표현 | 기본 재질과 조명 반응형 재질의 차이 |
| 5 | 본체·문·표시창으로 장비 구성 | `group`, 상대 좌표, 컴포넌트 props |
| 6 | 장비 4대와 가운데 통로 배치 | TypeScript 타입, 배열과 컴포넌트 재사용 |
| 7 | 장비 클릭 시 이름 표시 | 포인터 이벤트, React 선택 상태 |
| 8 | 장비 상태에 따라 색상 표시 | 상태 타입, 데이터에 따른 화면 변경 |
| 9 | 운반체가 두 지점 사이를 왕복 | `useFrame`, `useRef`, 시간 기반 이동 |

각 단계는 **개념 설명 → 최소 구현 → 화면 확인 → 값 변경 실습**으로 진행한다. 한 번에 전체 단계를 구현하지 않고, 사용자가 다음 단계를 요청하면 이어간다.

Fiber 문법을 설명할 때는 Three.js와의 관계도 함께 짚는다. 예를 들어 `<mesh>`는 `THREE.Mesh`에 해당하며, `Canvas`가 장면·카메라·렌더러 구성을 맡는다는 점을 먼저 설명한다. [첫 장면 공식 안내](https://r3f.docs.pmnd.rs/getting-started/your-first-scene)

## 코드 구성과 인터페이스

- 처음에는 `App.tsx` 안에서 장면을 작성한다. 장비를 조립하는 5단계에서 `Equipment.tsx`를 분리한다.
- 장비 컴포넌트는 이름, 위치, 상태를 props로 받는다. 배치 데이터는 여러 장비가 등장하는 6단계에 추가한다.
- 위치 타입은 `[number, number, number]`, 장비 상태는 `'idle' | 'running' | 'error'`로 정의한다. 상태는 8단계부터 사용한다.
- 선택한 장비 ID는 React `useState`로 관리한다. 이름은 Canvas 밖의 HTML 패널에 표시하고, 빈 공간 클릭으로 선택을 해제한다.
- 운반체의 매 프레임 위치 변경은 ref로 처리한다. 애니메이션 프레임마다 React 상태를 갱신하지 않는다.
- TypeScript는 strict 설정을 사용하되, 학습에 필요한 props·튜플·유니언 타입부터 도입한다. 전역 상태 라이브러리와 백엔드는 추가하지 않는다.

## 확인 방법과 기본 가정

- 각 단계에서 TypeScript 검사와 프로덕션 빌드를 통과하고, 브라우저 콘솔 오류 없이 해당 결과가 보여야 한다.
- 화면 크기를 바꿔도 장면 비율이 유지되는지 확인한다.
- 조작 단계에서는 회전·확대·이동, 선택 단계에서는 장비 선택·해제와 이름 표시를 확인한다.
- 애니메이션 단계에서는 운반체가 두 지점 사이를 반복 이동하며, 프레임 속도에 따라 이동 속도가 달라지지 않는지 확인한다.
- 초기에는 별도 테스트 프레임워크 없이 타입 검사·빌드·수동 화면 확인으로 검증한다.
- 데스크톱 브라우저와 로컬 실행을 기준으로 한다. Y축은 높이, 1단위는 1m로 사용한다.
- 장비는 단순한 박스로 표현하고 치수는 학습용 임의 값으로 둔다. 지붕·외벽·외부 3D 모델·실제 공정 시뮬레이션은 이후 확장 대상으로 남긴다.
